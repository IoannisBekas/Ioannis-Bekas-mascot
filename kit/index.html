Mini Ioannis.

A handmade-felt-puppet version of Ioannis Bekas, generated with Higgsfield from a single headshot. He walks, types, sips coffee and points you to the contact details on his portfolio.

The character

One master image and a turnaround sheet keep him on-model in every scene. Both go in as references for every new image.

  • StyleMuppet-style felt hand puppet, shot like a real one
  • FaceSide-parted faux-fur hair, felt brows, stubble, big smile
  • OutfitNavy blazer, white shirt, charcoal chinos, brown sneakers
  • SetSeamless #f5f5f5 studio, locked-off camera

How he's made

All generation runs through the Higgsfield CLI. Every prompt and script is in the repo.

  1. CharacterNano Banana Pro turns the headshot into a felt puppet, then a turnaround sheet.
  2. Start frameA 16:9 still of the scene, framed like the others.
  3. End frameAn edit of the start frame that changes only the pose. align.py fixes any reframing.
  4. AnimateKling 3.0 Pro fills the 5 seconds between the two frames.
  5. Gradeflatten.py and encode.sh clamp the background to exactly #f5f5f5.
